## 1. 目标与原则

### 1.1 目标

| 维度 | 目标 |
|---|---|
| 功能完整度 | 覆盖 PRD §4 全部前端可见能力（94 项功能中约 70 项有界面）；无"点了没反应"的死链，未实现入口一律明确标注 |
| 信息密度 | 一屏可读：1280 宽下虚拟机列表可同时看到 ≥12 行含状态/资源/网络/操作；关键指标不藏在二级页面 |
| 状态可见 | 任何异步动作都有**进度 + 阶段 + 可查结果**；实时数据有"新鲜度"提示，断流可见 |
| 危险可控 | 高风险操作有醒目的**后果说明**而非只有"确定吗"；不可逆操作需二次验证（F-10-01） |
| 观感 | 双主题（深/浅）完整对等、统一动效与间距体系、无布局跳动、无裸原生控件 |
| 性能 | 首屏可交互 < 2s（内网、冷缓存）；路由切换 < 100ms；列表 500 行滚动不掉帧 |

### 1.2 设计原则

1. **数据优先**：界面服务于"看清状态、做出判断"。装饰性元素（渐变、玻璃、插画）只出现在**非工作区**（登录页、空态、引导），工作区保持克制。
2. **一屏一焦点**：每个页面只有一个主操作（主按钮唯一），其余操作降级为次要按钮或行内图标。
3. **状态即语言**：颜色、图标、文案三者一致地表达状态；**不允许仅靠颜色传意**（色觉障碍可用）。
4. **实时但不打扰**：数据静默更新，不用整页 loading/skeleton 打断阅读；用"刷新指示 + 时间戳"表达新鲜度。
5. **危险操作显式**：破坏性动作与安全动作**视觉区分**（危险色 + 确认 + 影响面清单），且不与主按钮相邻。
6. **可预测**：同样的资源在不同页面用同样的图标、颜色、操作顺序；表单字段顺序在创建与编辑间保持一致。
7. **不阻塞**：任何耗时操作立即返回任务号并让用户可继续操作，进度在底部任务栏可见（F-7-01/02）。

### 1.3 与参考项目的取向差异（同样是"不弱于"的取舍）

| 方面 | 参考项目 | 我们的取向 | 原因 |
|---|---|---|---|
| 主题默认 | 浅色默认，深色适配 | **深色为默认主题**，浅色完整对等（两套都要做到位） | 运维/监控长时间盯屏场景，深色降低眩光；两个主题都做全才算不弱 |
| 装饰风格 | 极光氛围背景 + 玻璃拟态全站化 | 装饰背景只用于登录页与空态；工作区用**分层中性色 + 1px 边框**表达层级 | 玻璃层叠在密集表格上会拉低对比度与可读性；也与渲染性能有关 |
| 动效 | 入场动画、脉冲、渐变等较丰富 | **保留功能性动效**（状态变化、进度、展开/收起、图层进入），去掉装饰性循环动画 | 长时使用场景下循环动画是干扰；减少合成层开销 |
| 信息密度 | 表格 + 卡片双视图，行高固定 | 双视图 + **密度开关**（紧凑 36 / 标准 44） | 大屏用户可一屏看更多，笔记本用户保持舒适 |
| 快捷键 | 基本没有 | **提供常用快捷键**（列表导航、新建、搜索、控制台） | 运维高频操作，这是"更强的功能"而非装饰 |

## 2. 技术栈与工程架构

### 2.1 技术栈

技术栈已由 [ADR-0006](../06-decisions/0006-frontend-tech-stack.md) 定稿（状态：Accepted）。主版本摘要：

| 类别 | 选型 |
|---|---|
| 构建 / 框架 / 语言 | Vite · React 19 · TypeScript（strict） |
| 样式 / UI 基础 | Tailwind CSS 4（`@theme` 令牌映射）· shadcn/ui（Radix 底座） |
| 路由 / 服务端状态 / 客户端状态 | React Router v7（**库模式**）· TanStack Query · Zustand |
| 表格 / 表单 / 图表 | TanStack Table + Virtual · React Hook Form + Zod · ECharts（自研轻封装） |
| i18n / 控制台 / Mock | i18next · noVNC · MSW |
| 测试 / 包管理 / 质量 | Vitest + React Testing Library · Playwright · pnpm · ESLint + Prettier |

**版本策略**：主版本以 ADR-0006 为准，具体小版本由 `web/pnpm-lock.yaml` 锁定，以落地时最新稳定版为准。

### 2.2 目录结构（`web/`，规划）

> 前端工程位于仓库根目录 `web/`（与 `cmd/`、`internal/` 平级），纯 SPA，构建产物由控制面托管。**目录尚未创建**——技术栈已由 [ADR-0006](../06-decisions/0006-frontend-tech-stack.md) 确认，创建时以本节为准。

```
web/
├── index.html                    # 页面入口
├── package.json                  # 依赖与脚本
├── tsconfig.json                 # 类型与路径别名（strict）
├── vite.config.ts                # 构建配置（分包策略、/api 代理）
├── public/                       # 不参与构建的静态资源（favicon、图标）
└── src/
    ├── main.tsx                  # 入口：挂载与全局初始化
    ├── App.tsx                   # 根组件：主题与全局装配
    ├── router/                   # 路由表 / 懒加载声明 / 登录与角色守卫
    ├── layout/                   # 全局框架（§5.1）
    │   └── components/           #   侧边栏 / 顶栏标签栏 / 底部任务栏 / 全局搜索
    ├── views/                    # 页面：一域一目录（对齐 §3.2 路由表）
    │   ├── auth/                 #   登录链路 / 邀请 / 找回密码
    │   ├── dashboard/            #   工作台（管理员 / 租户）
    │   ├── vm/
    │   │   ├── list/             #   列表（表格 / 卡片 / 批量操作）
    │   │   ├── create/           #   9 步创建向导
    │   │   ├── detail/           #   详情（7 个标签页）
    │   │   └── console/          #   控制台独立窗口（重依赖二次懒加载）
    │   ├── template/             #   模板
    │   ├── network/              #   网络中心（交换机 / 安全组 / ACL / 端口安全 / 端口镜像）
    │   ├── public-ip/            #   公网 IP
    │   ├── firewall/             #   防火墙
    │   ├── storage-pool/         #   存储池
    │   ├── my-storage/           #   我的存储
    │   ├── user/                 #   用户管理
    │   ├── node/                 #   节点管理（含 agent 纳管向导）
    │   ├── task/                 #   任务中心
    │   ├── scheduler/            #   调度事件
    │   ├── settings/             #   系统设置
    │   ├── security/             #   安全中心
    │   ├── api-docs/             #   API 文档
    │   └── about/                #   关于
    ├── components/
    │   ├── business/             # 业务组件（§4.7 清单，跨页面复用，禁止各页重写）
    │   └── common/               # 基础组件封装（按钮 / 表格 / 弹层 / 空态 / 错误态…）
    ├── api/                      # 请求层：一模块一文件，页面不直接拼 URL
    │   ├── client.ts             #   实例：鉴权 / 401 登出 / 428 二次验证自动重试
    │   └── sse.ts                #   SSE 通道封装（列表 / 详情 / 任务 / 宿主指标）
    ├── stores/                   # 全局状态五块（§4.9）：用户 / 任务 / 页面标签 / 高风险验证 / 列表缓存
    ├── hooks/                    # 跨域复用逻辑：SSE 订阅、主题、密度、快捷键
    ├── styles/
    │   ├── tokens.css            #   设计令牌 --kc-*（浅/深两套，§4.2 唯一落点）
    │   ├── base.css              #   全局重置与排版
    │   └── themes/               #   主题切换
    ├── types/                    # 契约类型（对齐 docs/03-api/API.md）
    ├── utils/                    # 格式化 / 上传器 / VNC 客户端
    └── locales/                  # 语言包（键值化，§7）
```

**组织规则**：

- **目录按"功能域"组织**，不按类型堆文件：域内的页面、组件、hooks、样式内聚在 `views/<域>/` 下（如 `views/vm/detail/components/`）；只有**跨域复用**的才升到顶层 `components/` 与 `hooks/`。
- **页面一律懒加载**（按路由分包），控制台 / 终端 / 编辑器 / 图表等重依赖二次懒加载（§6.7）。
- 所有接口调用集中在 `api/<模块>`，页面不直接拼 URL。
- **测试与被测代码同目录**（`*.test.ts(x)`）；E2E 用例放 `web/e2e/`。

### 2.3 数据与状态职责

| 层 | 承担 | 禁止 |
|---|---|---|
| TanStack Query | 全部服务端状态：请求缓存 / 失效 / 重试 / 分页；**SSE 推送写入缓存** | 不用路由 `loader` 取数（避免与 Query 双轨） |
| Zustand（`stores/`） | 仅纯客户端 UI 状态（§4.9 五块） | 域内私有状态不进全局 store |
| 组件局部状态 | 弹窗开合、表单临时输入等域内状态 | 跨域共享数据不得藏在页面内 |

**样式分层（三层桥接，方向唯一）**：设计令牌 `--kc-*`（唯一事实来源，§4.2）→ Tailwind `@theme` 映射 → shadcn 语义变量（`--background` 等）引用 `--kc-*`。**不允许三套变量并存**；业务代码只使用映射后的 utility 或令牌，禁止魔法值。

### 2.4 工程约定

- **组件只消费设计令牌**，禁止在业务代码里写颜色/间距魔法值（Lint 规则约束）。
- 类型来自后端契约；接口返回结构变更必须先改契约类型（对应 [`../03-api/API.md`](../03-api/API.md)）。
- 业务规则（运行态可改矩阵、字段联动、高风险清单、配额档位）由后端下发，前端只渲染与禁用，**不允许硬编码第二份**（§6.5）。
- **AI 生成约束**：组件边界以 §4.7 清单与 `components/` 目录为准，同类组件禁止在各页面重复实现；AI 自检回路 = `tsc --noEmit` + Vitest + Playwright（[`../05-ai/AI_DEVELOPMENT.md`](../05-ai/AI_DEVELOPMENT.md) §6）。

### 3.1 角色与菜单

**菜单按能力域分组**（组内顺序即侧边栏顺序），角色差异用"可见性"表达而非两套菜单定义：

### 3.3 导航约定

- **页面标签栏**（顶栏）：工作台为固定标签不可关闭；其余页面访问即注册标签，标题随资源名变化（虚拟机详情显示 VM 名 + 状态点）。
- **最近访问**：侧边栏底部固定"最近 6 台虚拟机"，点击直达详情。
- **深链**：所有详情/标签页状态写入 URL（如 `/vm/foo?tab=snapshot`），可分享、可刷新、可回退。
- **面包屑**：仅两层以上层级（如 网络中心 → 交换机 → 某交换机）出现，列表页不出现。

## 4. 设计系统

### 4.1 视觉语言

**关键词**：沉稳、精确、高密度、可信。
**做法**：中性灰阶层级 + 单一品牌主色 + 4 个语义色；层级靠"背景明度差 + 1px 边框 + 极轻阴影"表达，**不靠厚重阴影与模糊**；数值一律等宽对齐。

### 4.2 色彩令牌

令牌命名 `--kc-<语义>-<变体>`，浅/深两套值由 `[data-theme]` 切换。**业务代码只引用语义令牌，不引用具体色值。**

**中性层（灰阶）**

| 令牌 | 用途 | 深色（默认） | 浅色 |
|---|---|---|---|
| `--kc-bg-base` | 页面底色 | `#0E1116` | `#F6F7F9` |
| `--kc-bg-surface` | 卡片/面板 | `#151A21` | `#FFFFFF` |
| `--kc-bg-raised` | 悬浮/弹层 | `#1B222B` | `#FFFFFF` |
| `--kc-bg-sunken` | 表头/代码块 | `#0B0E13` | `#EFF1F4` |
| `--kc-border-subtle` | 分隔线 | `#232B36` | `#E3E6EB` |
| `--kc-border-strong` | 控件边框 | `#313B48` | `#D0D5DD` |
| `--kc-text-primary` | 主文本 | `#E6EAF0` | `#1D2430` |
| `--kc-text-secondary` | 次要文本 | `#A3AEBD` | `#5A6472` |
| `--kc-text-tertiary` | 提示/占位 | `#6F7B8A` | `#8A93A0` |

**品牌与语义色**

| 令牌 | 用途 | 深色 | 浅色 | 文案示例 |
|---|---|---|---|---|
| `--kc-brand` | 主操作、选中、链接 | `#3B9EFF` | `#1677FF` | — |
| `--kc-brand-hover` / `--kc-brand-active` | 交互态 | 明度 ±8% | 明度 ±8% | — |
| `--kc-success` | 运行中、成功、正常 | `#2FBF71` | `#12A150` | 运行中 / 已完成 |
| `--kc-warning` | 告警、临界、需注意 | `#E8A33D` | `#C77700` | 内存偏高 / 即将超限 |
| `--kc-danger` | 失败、危险、删除 | `#F0554D` | `#D92D20` | 已失败 / 强制断电 |
| `--kc-info` | 中性提示、处理中 | `#5B8DEF` | `#3B6EDB` | 处理中 / 排队中 |
| `--kc-idle` | 已停止、未知 | `#7A8699` | `#98A2B3` | 已关机 / 未知 |

**状态色语义（全局统一，不允许各页面另配色）**

| 对象 | 取值 → 颜色 |
|---|---|
| 虚拟机状态 | 运行中→success；已暂停/挂起→warning；已关机→idle；错误→danger；未知→idle（虚线边框） |
| 任务状态 | 排队→info；执行中→brand；成功→success；失败→danger；已取消→idle |
| 节点状态 | 在线→success；异常→danger；未知→idle；维护中→warning（叠加条纹） |
| 配额档位 | 0–70%→success；70–90%→warning；90–100%→danger；超限→danger + 只读标记 |

**要求**：以上色值在**两套主题下都需通过 WCAG AA 对比度**（正文 ≥ 4.5:1，图形/大字 ≥ 3:1）；色值可在实现时按对比度校验微调，但**语义与档位边界不可改**。

### 4.3 字体与数值

| 用途 | 规格 |
|---|---|
| 字体栈 | 系统 UI 字体栈（`-apple-system, "Segoe UI", "Noto Sans SC", …`）；等宽：系统等宽栈（表内数值、IP、ID、代码） |
| 字号 | 12（辅助/表头）/ 13（表格正文）/ 14（正文/表单）/ 16（小标题）/ 20（页面标题）/ 24（工作台大数） |
| 字重 | 400 正文 / 500 表头与强调 / 600 标题；**不使用 700 以上**（中文过粗） |
| 行高 | 正文 1.5；表格行 1.4；标题 1.3 |
| 数值 | 一律 `font-variant-numeric: tabular-nums`，右对齐；百分比保留 1 位小数，字节按 `KiB/MiB/GiB` 换算并保留 1 位 |
| IP / MAC / UUID | 等宽字体，可一键复制（点击即复制 + 轻提示） |

### 4.4 间距、栅格、圆角、阴影

- **间距刻度**：`4 / 8 / 12 / 16 / 20 / 24 / 32 / 40`（禁止 5、7、15 等游离值）。
- **栅格**：内容区最大宽度不设死；≥1600 用 12 列栅格，1280–1600 用 12 列自适应，<1280 收为 8 列；卡片间距统一 16。
- **页面内边距**：桌面 24；≤1180 收为 16。
- **圆角**：控件 6 / 卡片与弹层 10 / 徽标 999。
- **边框**：统一 1px；分隔线用 `--kc-border-subtle`，控件边界用 `--kc-border-strong`。
- **阴影**（仅三档，禁止自创）：`--kc-shadow-1`（卡片悬浮）、`--kc-shadow-2`（下拉/浮层）、`--kc-shadow-3`（模态）。

### 4.5 图标与插画

- 图标：线性风格、1.5px 描边、统一 16/20/24 三档；同一语义全局同一图标（如"强制断电"专用图标）。
- 状态点：8px 圆点 + 可选外圈；不能只用颜色，需与文案同时出现。
- 插画：仅用于**空态与引导**（新建向导首入、空列表、错误页），风格统一、单色 + 品牌色点缀，**不用于工作区**。

### 4.6 动效

| 场景 | 时长 | 缓动 | 说明 |
|---|---|---|---|
| 悬停/焦点/状态色变化 | 120ms | `cubic-bezier(0.2, 0, 0, 1)` | 最轻，不打断 |
| 展开/收起、标签切换 | 180ms | 同上 | 高度/透明度同动 |
| 弹窗/抽屉进入退出 | 240ms | 同上 | 进入：位移 8px + 淡入；退出必须走完动画再卸载 |
| 数值变化 | 不滚动动画 | — | 直接替换数字（滚动计数在监控场景是干扰） |
| 运行中状态点 | 2s 呼吸 | 循环但**可在设置中关闭** | 仅状态点，不作用于整卡 |

**硬性要求**：尊重 `prefers-reduced-motion`，该模式下所有非必要动效关闭；任何动效不得引起布局位移（CLS）。

### 4.9 交互与文案约定

- **弹窗生命周期**：常驻受控弹窗用 `visible`；按业务状态临时挂载的弹窗必须走"请求关闭 → 离场动画结束 → 父级回调"，避免直接卸载丢动画。
- **破坏性确认**：删除类必须列出**影响面**（如"将同时删除 2 块磁盘（共 120GB）"）；删除虚拟机、删除用户等需**输入资源名**确认。
- **开关文案**：状态文字放在组件内部且**每个状态仅 1 个字符**（开/关、允/拒、公/私），右侧不重复。
- **按钮文案**：动词 + 对象（"创建虚拟机"、"重置密码"）；同一动作全局同一措辞（禁用"新增"与"创建"混用）。
- **空态**：三段式——说明现状 + 为什么 + 主操作入口（如"还没有虚拟机 · 从 ISO 安装第一台"+ [创建虚拟机]）。
- **加载态**：首屏用骨架屏（结构一致）；局部刷新用**行内轻指示**（不遮罩）；**禁止整页 loading 遮罩**。
- **错误态**：区分"网络失败（可重试）"、"无权限（说明所需角色）"、"资源不存在（返回列表）"、"服务异常（带 request_id 供反馈）"四种。
- **时间格式**：相对时间（2 分钟前）为主，悬浮显示绝对时间（含时区）；表格中一律绝对时间（`MM-DD HH:mm`）。
- **全局 store 五块**：用户、任务、页面标签、高风险验证、列表缓存（只读投影，写完失效）。
- **快捷键**：`/` 聚焦搜索、`n` 新建（当前页主操作）、`g v` 跳虚拟机、`g t` 任务中心、`Esc` 关闭图层、`?` 快捷键面板。

### 5.2 工作台

**管理员版**（自上而下）：

1. **宿主状态横幅**：正常（success 底）/ 警告（warning 底）两态；告警项分行列出（CPU ≥90%、内存 ≥90%、存储剩余 <10GB、挂载点可用 <10GiB、**未配置 SMTP**）。
2. **统计卡 4 张**：CPU / 内存 / 磁盘 / 虚拟机数。每张含主数值、副标签（"当前 / 理论最大"）、**双进度条**：
   - 上层实心 = 当前使用量；下层斜纹 = 理论最大量；
   - 轨道按 `max(当前, 理论, 100%)` 归一化并画 100% 刻度线；
   - 口径：CPU = Σ(运行中 vCPU)/宿主核数；内存 = (系统基线 + Σ(运行中 VM 最大内存))/宿主内存；磁盘 = Σ(全部 VM 磁盘)/宿主磁盘（不受运行态影响）。
3. **内存卡 KSM / zRAM 区**：开启时显示"KSM 节省 xx"并可展开明细，zRAM 开启时进度条加第三段（压缩交换阶段）；未开启整块隐藏。
4. **"硬件详情"折叠区**（默认收起，收起即卸载面板并停止轮询）：CPU 型号与每核使用率色块网格（<10/40/70/90/≥90 五档）；内存已插/总插槽与每根内存条；数据缺失时给出中文说明并正常降级。
5. **宿主资源监控**：四图（CPU / 内存 / 网络 / 磁盘 IO）+ 实时/历史切换 + **按物理网卡、物理硬盘分设备筛选**。
6. **最近虚拟机**：5 行紧凑表（名称、状态、规格、IP、快捷电源）。
7. **异步任务卡**：当前任务 + 任务中心入口。

**租户版**：资源总览 5 卡（CPU / 内存 / 实例 / 磁盘 / 本月时长）→ 配额详情（计算与实例 / 存储 / 网络三类折叠）→ "我的资源追踪"（展开懒加载近 24h 迷你折线）。

### 5.3 虚拟机

#### 5.3.1 列表 `/vm`

- **工具条**：分组切换（全部 / 按状态 / 按模板 / 自定义）、视图切换（表格 / 卡片）、密度开关、搜索框（名称/备注/模板/标签，客户端过滤）、筛选标签、[新建虚拟机] 主按钮。
- **表格列**：选择框、名称（+状态点+锁定/救援徽标）、状态、配置（vCPU/内存 + **资源计量条**）、IP（多网口摘要，悬浮展开）、标签、备注/分组、操作。
- **分组**：分组头可折叠、组内全选、跨组多选；自定义分组按 `分组名` 聚合，未分组单独一组。
- **批量操作条**：选中后从底部浮出（"3 台已选 · 2 台运行中"）：开机 / 关机 / 重启 / 强制断电 / 删除。删除前提示"其中 1 台已锁定"。
- **行内操作**：电源（按状态动态可用）、[更多] 菜单（重置 / 编辑备注 / 编辑分组 / 制作模板 / 导出 / 重装系统 / 迁移 / 转为独立 / 救援 / 锁定 / 删除）。
- **标签编辑**：列表内直接增删（回车添加、点 × 移除，≤20 个、单个 ≤32 字符）。
- **电源按钮 loading 语义**：开机/关机/强制断电依赖状态变化解除；重启/重置接口确认后立即解除并静默刷新；关机指令成功但状态仍为 running 时，行内**只保留"强制断电"**。
- **实时**：进入即建 SSE，断线 5s 重连；从其它页返回先渲染缓存再静默更新。
- **空态**：插图 + "还没有虚拟机" + [从 ISO 安装] / [从模板克隆] 两个入口。
- **维护模式**：页面虚化 + 顶部提示条，禁用新建与电源操作。

#### 5.3.2 创建向导 `/vm/create`

步骤条固定 9 步（OVF-OVA 用卡片选择"跟随包配置 / 自定义"，不额外占步骤）：**创建方式 → 基础信息 → 硬件规格 → 存储介质 → 网络设置 → 系统配置 → 高级选项 → 硬件直通 → 确认信息**。

- **创建方式**：4 张卡片（ISO 安装 / 模板克隆 / 导入已有磁盘 / 导入 OVF-OVA），每张一行适用场景说明。
- **基础信息**：名称（+随机生成）、备注（0/200 计数）、系统类型卡片（Linux / Windows / 其他，含发行版举例）、系统版本（可搜索下拉）、批量数量。
- **硬件规格**：vCPU（含热添加上限提示）、内存、CPU 限制、虚拟化方案、机型、引导方式。
- **存储介质**：存储位置（默认存储池预选）、ISO 多选（首个为主安装盘）、系统盘大小（按 OS 给建议值）、磁盘格式、驱动类型、IOPS（总/读写，标注互斥）、额外数据盘、软盘。
- **网络设置**：默认网卡型号、网口列表（可增删，每口：交换机 + 安全组 + 型号）、端口安全允许地址。
- **系统配置**：引导顺序（拖拽）、Watchdog、开机自启、启动冻结、首次启动初始化方式（F-2-17）。
- **高级选项**：首次进入有"进阶设置提醒"遮罩；含开发者选项、CPU 拓扑与亲和性、显示设备、SPICE、RTC、Guest Agent、SMBIOS、直接内核引导。
- **硬件直通**：PCI 设备选择（仅管理员；提示"启动时自动绑定 vfio-pci"）。
- **确认信息**：按"基础 / 硬件 / 存储 / 网络与系统"分组摘要 + **预估资源占用** + 配额余量校验；有缺失项时禁用提交并给出定位链接。
- **联动规则**（前后端同源，§6.5）：Windows → UEFI + SATA + e1000e；ARM → virt 机型 + UEFI + ramfb；选 ISO 自动补系统类型与最小磁盘；切模板带出默认规格。
- **生命周期**：步骤 2 起自动保存草稿（localStorage，24h），意外刷新可恢复；提交后跳列表并高亮新行，任务栏显示进度。

#### 5.3.3 详情 `/vm/:name`

**Hero 三卡**：

1. **状态卡**：状态标签 + 运行时长 + 电源操作组（开机/关机/重启/强制断电/重置）+ 徽标区（锁定/救援/重装中）+ 备注编辑。
2. **资源卡**：CPU/内存计量条（含"动态内存"提示）、网络与磁盘 IO 实时速率、配置摘要（机型、引导、模板来源）。
3. **控制台预览卡**：VNC 截帧（每 20s），点击进控制台，支持独立窗口打开；显示设备为 none 时隐藏该卡。

**标签页**（惰性挂载，仅当前可见标签拉数据）：

| 标签 | 内容 |
|---|---|
| 系统信息 | 规格、PCIe 热插槽用量（余量 ≤1 警告）、系统盘缺失警告、操作系统、机器类型、模板来源、连续运行时长的；**登录凭证**（显示/复制、在线与离线重置密码）；**IP 列表**（按网口汇总 IPv4/IPv6，多来源解析 + 三种可执行提示）；公网 IP（未配置则隐藏）；VNC 端口 / 网络接口 / 显示设备；高级设置（自启、冻结、APIC/PAE、Guest Agent 状态、CPU 限制、亲和性、内存策略）；磁盘 IOPS 限制表 |
| 快照管理 | 列表（名称/时间/类型/状态/描述/操作）、创建（含内存与否、UEFI 修复引导）、恢复、删除、删除全部；配额徽标"已用/上限"；外部快照与含子快照的**专项提示** |
| 网络管理 | 子标签：端口转发（含"立即开通"引导）、静态 IP 与租约、运行状态（管理员）、网络诊断与抓包（管理员） |
| 定时任务 | 列表 + 新增（一次性/每天/每周多选、动作 开机/关机/删除）；删除类仅允许一次性并走二次验证 |
| VNC 控制台 | 状态、开关、改密、对外暴露（高风险 + 重启生效）、打开独立窗口 |
| SPICE 控制台 | 状态（未开启/仅本地/已暴露）、开关、改密、暴露、`.vv` 下载（F-2-09，P2） |
| 编辑 | 见下 |

**编辑**：子选项卡（基础配置 / 磁盘与驱动器 / 启动与安全 / 网口 / 直通 / 高级）；加载时冻结快照，**保存只提交变化字段**；运行态可改项标"可热改"，须关机项标"需关机"并禁用提交；未保存时切换标签或离开页面给出提示。

**实时与失焦**：详情 SSE 每 3s 全量推送；**失焦 10s 断开、聚焦立即重连**并重置速率增量基准；配置类区块用"配置签名"区分统计心跳与配置真变化，仅后者重建表单；编辑中的未提交输入不被后台同步覆盖。

#### 5.3.4 控制台独立窗口 `/vm/:name/console`

无主布局；顶部工具条（连接状态、缩放自适应、发送 Ctrl+Alt+Del 与常用组合键、发送文本、粘贴已保存凭据、全屏）。断线自动重连并提示重试次数；VNC 未开启时给出"开启 VNC"引导。

### 5.4 模板 `/template`

- **列表**：模板族树形（父模板 → 版本子节点），支持"全部展开/收起"；卡片视图展示缩略图（无图用系统类型图标）、系统类型/版本、磁盘大小、默认规格、克隆次数、发布状态徽标。
- **行内操作**：创建虚拟机、编辑元数据、发布设置、导出、删除（含级联/提升/热提升三种删除策略选择 + 影响预览）、查看关联虚拟机。
- **顶部**：[从虚拟机制作模板]（选择关机态 VM）、[导入模板包]（上传或主机绝对路径 + 解析预览）。
- **详情**：基本信息、默认创建配置、关联虚拟机列表、族谱关系图。
- **空态**：引导"从一台已配置好的虚拟机开始制作"。

### 5.5 网络中心 `/network`

Tab 结构：**网络概览 / 交换机 / 安全组 / ACL / 端口安全 / 端口镜像**。

- **概览**：基础网桥卡片（名称、模式、上行口、地址与 DHCP 范围、状态）、OVS 状态与[修复]入口（F-4-13）、端口与租约概览。
- **交换机**：表格（名称、归属、模式、VLAN、网段/网关、上下行带宽、月流量、状态、操作）；新建弹窗含模式卡片选择（空交换机 / 物理直通 / 内置 DHCP-NAT）+ 配额区（带宽、月流量，"0 = 不限"）+ 模式说明；运行中变更走二次验证。
- **安全组**：组列表 + 规则表（方向、协议、端口范围、目标类型 CIDR/交换机/安全组、备注）；方向决定动作（入站放行/出站拒绝），不显示独立 action 字段；提供默认组标记与"每用户默认组"说明。
- **ACL**：规则汇总预览（按 VM 与网口展开生效结果）→ [应用]（高风险）。
- **端口安全**：状态标签（需要处理 / 已关闭）+ "已应用 N 个端口、兼容保护 N 个、隔离 N 个、最近协调时间" + **端口策略明细表** + 预检/启用/禁用/协调操作。
- **端口镜像**：来源接口多选、目标空交换机多选、方向（双向/仅入/仅出）、vlan 保留开关；启用前提示"建立自动回滚看门狗"并显示倒计时；停止镜像需二次验证。

### 5.6 公网 IP `/public-ip` 与 防火墙 `/firewall`

- **公网 IP**：筛选（地址族 / 状态 / 模式）→ 表格（IP、CIDR、网关、出口网卡、支持模式、绑定对象、运行态）→ 操作（绑定 / 解绑 / 预览 / **浮动迁移** / 批量）；新建支持单条与批量、模式多选；IPv6 明确标注"无 NAT、走 Proxy NDP"。
- **防火墙**：
  - **宿主机**：开关（含开启/关闭预览）、规则表（动作、协议、端口区间、来源 CIDR、备注、保护标记）、快捷按钮"添加 VNC 5900-5999"、容器运行时兼容提示、[紧急回滚]；
  - **KVM 网络**：全局策略（默认动作、区域、白名单优先）、按虚拟机的覆盖策略列表、预览 → 应用 → 回滚；
  - **连接管理**：连接表（`established` 列表）+ 范围切换（非防火墙端口 / 全部）+ 先预览后关闭（二次验证）。
- **保护规则**：由后端标记（SSH 与面板端口），界面**标红且不可编辑**，与端口转发自动放通规则视觉区分。

### 5.7 存储

- **存储池 `/storage-pool`**：空间分配条（已用 / 可用 / **未挂载 / 未分配**）、磁盘表（设备、型号、容量、文件系统、挂载点、用途）、操作（格式化并挂载、创建/删除分区、设为默认、创建存储卷）；创建卷弹窗：类型（LVM / Btrfs 标注"即将推出"）→ 配置（多盘聚合，条带 / 镜像）；所有破坏性操作提示数据影响并二次验证。
- **我的存储 `/my-storage`**：未开通时引导卡片（说明将获得 ISO 镜像 / 文件共享 / 虚拟磁盘三类空间 + 配额）→ [开通]；开通后：配额卡（4 档配色，超限转只读并提示）+ 三个分类标签 + 文件表格（名称、大小、类型、识别出的系统版本、上传时间、操作）+ [上传]。
  - **上传器**：拖拽/选择 → 秒传命中直接完成 → 否则分片上传（进度、速度、剩余时间、暂停/继续、失败分片重试）；"未完成上传"列表可恢复。
  - **挂载**：选择目标虚拟机 → tag、安全模型（mapped/passthrough）、只读开关 → 提交为任务；已挂载列表可卸载。

### 5.8 用户与节点

- **用户管理 `/user`**：表格（用户名、角色、类型、状态、配额用量摘要、SSH 开关、最近登录）；新建/编辑弹窗（账号、邮箱、初始密码 + 随机生成、角色、配额组，SMTP 未配置时提示"必须设置初始密码"）；操作：封禁/解封（**级联动作预览**：置状态 → 关 SSH → 关运行中虚拟机）、重置流量、重发邀请、删除（输入用户名确认）。
- **节点管理 `/node`**：卡片或表格（名称、agent 状态点、agent 版本、最近心跳、可迁移标记、维护模式开关、能力摘要）。
  - **纳管向导（三步）**：① 填节点名 → 生成**一次性注册令牌**与安装命令（含控制面地址，可复制，可设有效期）；② 在物理机执行命令，向导内显示"等待 agent 接入…"；③ agent 上线后展示**自报能力清单**（虚拟化命令与版本、网桥 / OVS 能力、IOMMU、目录与权限），逐项标注"可用 / 缺失（并说明影响哪些功能）/ 不支持"。
  - **离线与陈旧数据**：节点离线时状态点变灰并标注"离线 · 最后心跳 x 分钟前"；进入该节点相关页面时顶部显示**陈旧数据横幅**，新建类操作禁用并给出原因（F-6-02/08）。
  - **操作**：撤销注册（二次确认）、重新生成令牌、维护模式切换、查看 agent 与协议版本、查看最近错误、**重新自检能力**（让 agent 重跑探测并回传）。

### 5.9 任务与调度

- **任务中心 `/task`**：筛选（类型 / 状态 / 资源 / 时间范围）+ 表格（任务号、类型、关联资源、发起人、状态、进度、耗时、操作）+ 详情抽屉（参数、**阶段列表**、结果 JSON、错误、日志片段）+ 取消（二次确认）+ 清理已完成。
- **调度事件 `/scheduler`**：调度器概览卡片（key、启用状态、分组、说明、最近事件时间）+ 事件表（时间、调度器、范围、结果、消息）+ 实时开关；明确"只记录实际发生的调度动作，不记录普通轮询"。

### 5.10 系统设置与安全

- **系统设置 `/settings`**：Tab（基础 / 存储与网络 / 宿主机 / 调度与高级 / 安全与维护 / 日志 / 诊断导出）。**每个配置项标注对应环境变量名**；说明"常规配置保存后立即生效并持久化；宿主机级选项写入系统配置文件且环境变量优先"；即时生效且可能失败项提供回滚按钮并展示回滚结果。
- **日志管理**：级别调整、在线查看（关键词/时间过滤、**响应体脱敏**标记）、导出、清理。
- **诊断导出**：分类多选（配置 / 日志 / 运行时状态 / 网络）→ 导出为任务 → 完成后下载。
- **安全中心 `/security`**：Tab（邮箱绑定 / 两步验证 / API 凭证 / 修改密码 / 修改用户名）+ 会话与登录记录（设备、IP、时间、当前会话标记、可撤销其他会话）。敏感项走高风险二次验证；恢复码展示为一次性网格并要求"已安全保存"勾选。
- **API 文档 `/api-docs`**：左侧模块树（按域分组）→ 右侧接口详情（方法、路径、认证要求、参数表、请求/响应示例、可复制 curl、高风险标记）。由路由与接口定义**生成**，避免手写漂移。
- **关于 `/about`**：版本信息、组件版本、依赖清单、许可证、仓库链接。

## 6. 跨页交互规格

### 6.1 实时通道

| 通道 | 推送节奏 | 断线策略 | 失焦策略 |
|---|---|---|---|
| **节点心跳 / 状态**（控制面 ↔ agent） | 心跳约 10s；能力与运行态在重连时全量对账 | 心跳超时即判离线，界面标"陈旧"并停止向该节点下发新任务 | — |
| 虚拟机列表 | 2s 增量 | 5s 重连，重连后全量对账 | 保持（列表页通常后台可见） |
| 虚拟机详情 | 3s 全量 | 同上 | **10s 后断开**，聚焦立即重连并重置速率基准 |
| 任务进度 | 事件驱动 | 5s 重连，重连后补齐未完成任务的当前状态 | 保持 |
| 宿主指标 | 5s | 同上 | 保持 |
| 会话失效 | 事件 `session_expired` | — | 统一跳登录并保留回跳地址 |

**新鲜度提示**：实时数据区右上角显示"实时 · 3s 前更新"，断流时变为"已断开 · 重连中(n)"并使用 warning 色。

### 6.2 高风险二次验证（F-10-01）

统一流程：请求 → 后端返回 428 → 前端弹出验证框（2FA 动态码 / 恢复码 / 邮箱验证码）→ 验证通过 → **自动重试原请求**。要求：单飞加锁（同一时刻只允许一个验证流程）、防死循环（重试仅一次）、验证失败给出剩余尝试次数、验证后原请求参数原样重放。

### 6.3 异步任务与进度

- 提交后**立即**返回并 Toast"任务已提交 · 查看进度"，同时任务栏出现进度条。
- 进度条显示"类型 + 当前阶段 + 百分比"；多阶段任务（如创建虚拟机）在任务详情中展示阶段列表与每阶段耗时。
- 失败时任务栏变红并显示原因摘要，点击展开详情（含失败阶段与可重试阶段）。
- **取消**：等待中的任务直接标记；运行中的任务发出取消信号并提示"部分已完成步骤可能不会回滚"。

### 6.4 长表单（创建向导 / 编辑）

- 草稿自动保存（仅创建向导，24h）；离开前拦截提示。
- 分步校验：下一步前只校验当前步；提交前做完整校验并**汇总缺失项**，点击可定位到具体步骤与字段。
- 字段联动即时生效（如选择 Windows 自动切换机型/磁盘/网卡），并**说明为什么改**（字段下方灰字）。
- 运行态约束：需关机的字段在运行态下禁用并显示"需关机后可改"，热改项标注"可热改"。

### 6.5 前后端规则同源

"运行态可改矩阵"、"字段联动规则"、"高风险操作清单"、"配额档位"这四类规则由**后端作为唯一事实来源**下发（接口或配置），前端只做渲染与禁用，**不允许前端硬编码第二份**。

### 6.6 主题与个性化

- 主题切换：浅色 / 深色 / 跟随系统；切换即时生效且不闪烁（令牌驱动）。
- 列表密度、侧边栏折叠、任务栏高度、是否显示呼吸动效：用户偏好持久化（本地）。

### 6.7 性能预算

| 项 | 预算 |
|---|---|
| 首屏 JS（gzip） | ≤ 250KB（登录页 ≤ 120KB） |
| 路由切换 | ≤ 100ms 出骨架，≤ 300ms 内容可读 |
| 列表渲染 | 500 行内直接渲染；>500 行走虚拟滚动；带宽按需 |
| 图表 | 单页最多同时渲染 4 张；数据点 >2000 时降采样 |
| 实时 | 单页最多 2 条 SSE 连接；SSE 消息处理 < 5ms |
| 长任务依赖 | VNC / 终端 / 编辑器 / 图表**全部懒加载**，不进首屏包 |

## 7. 可访问性与国际化

- **键盘**：所有操作可键盘完成；焦点可见（2px 品牌色描边）；弹层打开后焦点锁定、关闭后归还；表格支持方向键行导航。
- **对比度**：正文 ≥ 4.5:1、图形与大字 ≥ 3:1（两套主题均需通过）；禁用态不低于 3:1。
- **语义**：图标按钮必须有 `aria-label`；状态同时用颜色 + 文字 + 图标；表单 label 与控件关联，错误信息用 `aria-describedby`。
- **动效**：尊重 `prefers-reduced-motion`。
- **国际化**：文案集中在语言包，禁止在组件内硬编码中文；后端返回稳定错误码，前端映射可读文案；时间与数字按 locale 格式化（默认 `zh-CN`）。
