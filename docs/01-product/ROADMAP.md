**规则**：AI 拆解任务时**不应越界实现后续阶段的功能**；阶段目标变更需更新本文件，并在 [`../../CHANGELOG.md`](../../CHANGELOG.md) 记录。

## 阶段总览

| 阶段 | 主题 | 状态 | 覆盖口径 |
|---|---|---|---|
| M0 | 基础设施 | 已完成 | 工程与文档体系就绪 |
| M1 | 技术选型与骨架 | 已完成 | 技术栈定稿 + 可构建可启动骨架 |
| M2 | 最小可用（MVP） | **基本完成**（节点代理一项除外，转入 M5） | 底座打通 + 单机完整生命周期（P0 22 项） |
| M3 | 功能完善 | **已完成** | L1 资源能力补齐 + L2 运营治理主体（P1 46 项） |
| M4 | 稳定加固 | **控制面部分已完成**（压测 / 可观测性 / 降级核对随 agent） | P2 收尾 + 多节点 + 非功能需求 |
| M5 | 真实 agent 与正式发布 | **未开始（当前唯一主线）** | agent 落地 → 全量验收 → 上线 |

> 2026-09-28 重写说明：上一版（2026-09-15）的勾选状态长期滞后于实际进展——四轮对标（G-01 ~ G-54 全部收口）与热迁移 / 多节点补齐之后，原 M2/M3/M4 的条目绝大多数已完成。本版按实际状态重写，并把**真实 agent** 提为独立的收尾阶段（M5）：它是控制面之外唯一剩的整块工作，也是"可演示"到"可管理真实宿主机"的分水岭。
