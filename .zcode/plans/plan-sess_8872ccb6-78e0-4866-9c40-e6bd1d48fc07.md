# 真实 Agent 构建：分期实现计划（feat/agent 分支）

## 依据（不重新决策的部分）

- 传输协议**已由 f-6-01 §5.2 定稿**：gRPC over TLS（mTLS）双向流 + Protocol Buffers v3；一次性注册令牌 → 换 mTLS 客户端证书；心跳 10s、离线阈值 40s；重连指数退避（1s×1.6 上限 60s±20%）；VNC 走独立多路复用字节流（不落盘不进日志）；断连自治 + 重连对账。本次不另开传输选型 ADR，直接按规格实现。
- **契约零改动**：控制面 123 个 OpKind、Client/StreamOpener/SnapshotProvider 三接口、阶段上报语义（OnStage 容忍漏报）、Result 语义（error=未送达 ≠ Success=false=执行失败）全部维持，agent 是把它们做真。
- **测试机**：192.168.64.2（ARM64 Linux，已跑 QVMConsole，libvirt/OVS 环境现成）。红线：**不破坏 QVMConsole**；密码只用于首次配置 SSH 密钥登录，**IP/密码绝不写入仓库任何文件**；危险网络操作（uplink/防火墙）必须用规格内置的看门狗机制并逐步验证回滚。

## 新增依赖（AGENTS.md 要求说明理由）

| 依赖 | 理由 |
|---|---|
| google.golang.org/grpc + google.golang.org/protobuf | f-6-01 已定的传输与 IDL |
| github.com/digitalocean/go-libvirt | 纯 Go libvirt 客户端（**无 CGO**，可从 macOS 交叉编译 linux/arm64，符合项目零 CGO 约束）；`virsh` 命令作为降级路径 |
| buf（go install，仅开发期） | 纯 Go 的 proto 编排器，免装系统级 protoc |

## 目标结构（遵循 ADR-0012 分层）

```
cmd/agent/                    # agent 二进制入口（enroll 子命令 + daemon）
internal/agentproto/          # agent.proto（Bootstrap/Channel/Execute/VNC 四个 RPC）+ 生成代码
internal/agent/hub/           # 控制面侧：连接注册表，实现 agent.Client + StreamOpener + SnapshotProvider，
                              # 心跳落库（复用 repository/node），gRPC 服务端（Bootstrap 发证 + 路由 Execute 到对应连接）
internal/nodeagent/           # agent 侧：执行器注册表（OpKind → 本地执行），system 探测封装（libvirt/lsblk/nft/OVS…）
deploy/agent/                 # systemd unit 模板与安装脚本（无任何密钥）
docs/07-specs/f-6-08-agent.md # agent 规格（分期补全）
```

`cmd/server/wire_node.go` 的 `AGENT_TRANSPORT` switch 接入 `grpc` 分支（mock 分支原样保留，E2E 继续跑 mock）。

## 分期路线（每期一个可验收里程碑 + 真机测试清单）

**P0 通道骨架（本次首个里程碑）**
proto 三消息族（Register/Heartbeat/Execute+Stage/VNC 流）；cmd/agent（enroll 换证书、证书持久化 /var/lib/k_cockpit-agent、重连退避、心跳、能力自报、未实现操作返回明确 "not implemented"）；控制面 hub + gRPC 服务端 + 真实注册链路（`/dev/agent-register` 仅 mock 用，真实 agent 走令牌）；Execute 全链路（含阶段上报透传）。
✅ 真机验收：agent 注册 → 面板节点列表显示 **online**（真实心跳 40s 判定）、断网 40s 内变 offline、重连自动恢复；日志无敏感信息。

**P1 只读探测全真（面板"看得见"）**
node.stats / node.disks / node.network / node.domains / vm.status / vm.stats / vm.disk.list / vm.xml / vm.pcie.info / vm.neighbor / host.stats / host.hardware / host.netstats / host.tuning / host.iommu / host.pci.devices / ovs.status / ovs.ports / dhcp.leases / network.probe / platform.check / host.connections / vm.migrate.assess。
✅ 真机验收：工作台指标曲线来自真机 /proc 与 libvirt；节点详情五个页签数据与手工 virsh/lsblk 输出一致（写对账脚本比对）。

**P2 VM 生命周期 + 控制台**
vm.create/clone/delete、电源五操作、快照三件套、config.update、cdrom、console.frame、**VNC 流打通**（浏览器里看到真机虚拟机画面）。
✅ 真机验收：面板创建 ARM64 虚拟机 → 开机 → noVNC 真实画面 → 快照 → 恢复 → 删除；导出 qemu-img 磁盘可核对。

**P3 网络（危险，看门狗护航）**：bridge/vpc-switch/安全组/端口转发/双层防火墙/公网 IP/端口安全/镜像/抓包。逐项真机验证且先验证回滚路径。
**P4 存储与模板**：池/分区/LVM 卷/trim/文件上传下载/模板制备导出导入/重装/导出。

每期完成：`go build/vet/gofmt/test` 全绿 + mock 栈 E2E 5/5 + 真机清单逐项过 + commit。**协议兼容**：ProtocolVersion=1；字段只增不改。
